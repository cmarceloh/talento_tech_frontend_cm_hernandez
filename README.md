# Pizzarella - E-Commerce de Pizzería Artesanal

Este proyecto es la **Pre-Entrega de Proyecto Obligatoria** para el curso de **Front-End Developer**. Consiste en un sitio web e-commerce dedicado a la venta online de pizzas artesanales a la piedra.

## Propósito del Proyecto

Crear una plataforma responsiva, accesible e interactiva que permita a los usuarios explorar la carta de productos, leer testimonios de clientes, conocer la historia de la pizzería y contactarse con el local.

## Estructura del Sitio Web

- `index.html`: Página principal con banner de bienvenida, catálogo de productos (Cards) y sección de reseñas.

- `pages/sobreNosotros.html`: Página sobre la historia, valores y video promocional del proceso de elaboración.

- `pages/contacto.html`: Formulario de contacto funcional mediante Formspree y ubicación del local.

- `css/styles.css`: Estilos unificados, variables, diseño con Flexbox, CSS Grid y Media Queries.

- `js/script.js`: Archivo de JavaScript para futuras interactividades.

## Tecnologías Utilizadas

- **HTML5 Semántico**: Uso de `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, y `<footer>`.

- **CSS3 Moderno**:
  - **Flexbox**: Aplicado en el menú de navegación y en las tarjetas de productos (4 por fila en desktop).
  - **CSS Grid**: Aplicado en la sección de reseñas de clientes.
  - **Media Queries**: Garantizan adaptabilidad total para computadoras, tablets y celulares.

- **Formspree**: Integración para el envío funcional del formulario de contacto.

- **FontAwesome**: Iconografía vectorial para botones y redes sociales.

- **Google Fonts**: Tipografía 'Poppins'.
